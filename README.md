# 마비노기 쌀 콜렉터 (Mabinogi Rice Collector)

마비노기 경매장을 실시간으로 감시하는 **Windows 11 이상용 단독 실행 프로그램**입니다.

넥슨 Open API로 지정한 아이템의 경매장 가격을 추적하다가, **특가 매물**(최저가가 차순위가의 10% 이하)이 등록되면 Windows 토스트 알림으로 즉시 알려줍니다. 설치도, 별도 런타임도 필요 없습니다 — exe 하나면 끝입니다.

> v1은 Python 기반 Discord 봇이었습니다. v2부터 Go로 재작성된 GUI 앱이며 Discord 연동은 제거되었습니다. 기존 사용자는 [v1에서 마이그레이션](#v1에서-마이그레이션)을 참고하세요.

## 주요 기능

- **실시간 가격 감시** — 설정한 주기(기본 60초)마다 등록 아이템의 경매장 가격을 자동 확인
- **특가 알림** — 최저가 ≤ 차순위가 × 10% 이면 Windows 토스트 알림 + 프로그램 내 알림 로그
- **중복 알림 방지** — 같은 특가 매물로는 한 번만 알림, 가격이 바뀌거나 특가가 해제 후 재등장하면 다시 알림
- **트레이 상주** — 창을 닫아도 시스템 트레이에서 감시가 계속됨
- **안전한 키 보관** — 넥슨 API 키는 Windows 자격 증명 관리자에 저장 (디스크에 평문 파일 없음)

## 설치

1. [Releases](../../releases) 페이지에서 최신 `mabinogi-rice-collector.exe`를 다운로드합니다.
2. 원하는 위치에 두고 실행합니다. 설치 과정이 없습니다.

### SmartScreen 경고가 뜬다면

이 프로그램은 코드 서명이 되어 있지 않습니다(개인 오픈소스 프로젝트라 유료 인증서를 쓰지 않습니다). 처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**을 누르세요.

다운로드한 파일이 릴리스 원본과 같은지 확인하려면 PowerShell에서:

```powershell
Get-FileHash .\mabinogi-rice-collector.exe -Algorithm SHA256
```

출력된 해시를 릴리스에 첨부된 `SHA256SUMS.txt`와 비교하면 됩니다.

## 첫 실행 설정

### 1. 넥슨 API 키 발급

1. [넥슨 개발자센터](https://developers.nexon.com/) 접속
2. 로그인 후 **애플리케이션 등록**
3. **마비노기** API 선택
4. 발급된 API 키 복사

### 2. 프로그램에 키 입력

첫 실행 시 설정 창이 자동으로 열립니다. 발급받은 API 키를 붙여넣고 저장하세요.

- 키는 **Windows 자격 증명 관리자**(제어판 → 자격 증명 관리자 → Windows 자격 증명)에 저장됩니다. 프로그램 폴더나 설정 파일에 평문으로 남지 않습니다.
- 참고: 자격 증명 관리자는 같은 Windows 사용자 계정 경계까지 보호합니다. 다른 사용자 계정에서는 읽을 수 없지만, 내 계정에서 실행되는 프로그램은 접근할 수 있습니다.

## 사용법

| 동작 | 방법 |
|---|---|
| 아이템 추가 | 왼쪽 입력창에 아이템 이름 입력 후 **추가** (또는 Enter) |
| 아이템 제거 | 목록에서 해당 아이템의 **제거** 버튼 |
| 감시 시작/중지 | 상단 **감시 시작/중지** 버튼 |
| 설정 | 상단 **설정** 버튼 |
| 창 닫기(X) | 트레이로 최소화 — 감시는 계속됩니다 |
| 완전 종료 | 트레이 아이콘 우클릭 → **종료** |

- 아이템 이름은 부분일치로 검색됩니다. 예: `마나 허브`는 `축복받은 마나 허브`도 잡습니다.
- 아이템 이름에 쉼표(`,`)는 사용할 수 없습니다 (넥슨 API의 다중 검색 구분자).
- 아이템 목록 변경은 다음 감시 사이클부터 반영됩니다.
- 오른쪽 로그 화면에서 조회 내역과 알림 기록(🚨)을 볼 수 있습니다. 로그는 `%APPDATA%\mabinogi-rice-collector\app.log`에도 남습니다.

### 알림 예시

```text
🚨 마나 허브 특가! 일반 1,200 / 최저 100 / 할인율 91.7%
```

## 설정

| 항목 | 기본값 | 설명 |
|---|---|---|
| 넥슨 API 키 | — | Windows 자격 증명 관리자에 저장. 변경할 때만 다시 입력 |
| 폴링 주기(초) | 60 | 감시 사이클 간격. 최소 1초 |

일반 설정(아이템 목록, 주기)은 `%APPDATA%\fyne\com.github.myeonghan-nim.mabinogi-rice-collector\preferences.json`에 저장됩니다.

## API 제한 사항

넥슨 Open API는 애플리케이션 단계에 따라 요청량이 제한됩니다:

| 단계 | 초당 | 일일 |
|---|---|---|
| 개발 | 5건 | 1,000건 |
| 서비스/런칭 | 500건 | 20,000,000건 |

**개발 단계 키 기준 하루 요청 수 = 아이템 수 × (86,400 ÷ 주기 초)** 입니다. 이 값이 1,000을 넘지 않게 주기를 잡으세요.

- 아이템 1개, 주기 90초 → 960건/일 (OK)
- 아이템 2개 → 주기 180초 이상 권장
- 기본값 60초는 아이템 1개일 때도 1,440건/일이라 개발 단계 키로는 하루를 못 채웁니다. 오래 켜둘 거라면 주기를 늘리거나 넥슨 개발자센터에서 서비스 단계로 전환하세요.

제한을 초과하면 `OPENAPI00007`(HTTP 429) 오류가 로그에 찍힙니다. 프로그램은 멈추지 않고 다음 사이클에 다시 시도합니다.

## 작동 원리

1. 설정한 주기마다 등록된 각 아이템에 대해 넥슨 Open API `auction/keyword-search`를 호출
2. 응답 매물을 개당 가격 오름차순 정렬 후, 표시 이름에 검색어가 포함된 것 중 최저가·차순위가 추출
3. **최저가 ≤ 차순위가 × 10%** 이면 특가로 판정
4. 토스트 알림 + 인앱 로그 기록. 같은 가격의 특가가 유지되는 동안은 다시 알리지 않음

## v1에서 마이그레이션

v2에서 바뀐 것:

- **Discord 연동 제거** — 봇, 채널 알림, `!추가`/`!제거`/`!목록` 명령이 모두 사라졌습니다. 아이템 관리는 GUI에서 합니다.
- **`.env` 파일 불필요** — API 키는 첫 실행 시 GUI로 입력합니다. 자동 이전은 없으니 키를 다시 입력해 주세요.
- v1의 `.env` 파일에는 API 키와 Discord 토큰이 평문으로 남아 있습니다. **더 이상 쓰지 않으니 삭제를 권장합니다.**
- Python, systemd 서비스 등록도 더 이상 필요 없습니다.

## 개발 및 빌드

```bash
# 로직 테스트 (GUI 미포함 — 어느 OS에서나 가능)
go test ./internal/...
```

전체 앱은 cgo(Fyne)가 필요해 Windows 네이티브 또는 mingw 크로스 컴파일로 빌드합니다:

```bash
# Windows에서
go build -trimpath -ldflags "-H windowsgui -s -w -extldflags=-Wl,--subsystem,windows" -o mabinogi-rice-collector.exe .

# WSL2/Linux에서 (mingw 없이 Docker로 — 이미지는 zig를 C 컴파일러로 사용)
docker run --rm -v "$PWD":/app -w /app \
  -e CGO_ENABLED=1 -e GOOS=windows -e GOARCH=amd64 \
  -e CC="zig cc -target x86_64-windows-gnu" -e HOME=/tmp \
  fyneio/fyne-cross-images:windows \
  go build -trimpath -ldflags "-H windowsgui -s -w -extldflags=-Wl,--subsystem,windows" -o mabinogi-rice-collector.exe .
```

아이콘/매니페스트는 `winres/`에서 [go-winres](https://github.com/tc-hib/go-winres)로 생성한 `rsrc_windows_amd64.syso`로 임베드됩니다.

### 릴리스 자동화

main 브랜치에 푸시되면 GitHub Actions가:

1. 테스트 실행
2. [conventional commit](https://www.conventionalcommits.org/) 메시지로 semver 태그 생성 (`fix:` → patch, `feat:` → minor, `feat!:`/`BREAKING CHANGE` → major; `docs:`/`chore:` 는 릴리스 없음)
3. Windows exe 빌드 후 SHA-256 체크섬과 함께 GitHub Release에 첨부

PR에는 테스트+빌드 검증(ci.yml)이 돌아갑니다.

## 문제 해결

### 로그에 `API 키 인증 실패`

넥슨 개발자센터에서 키를 확인하고 설정 창에서 다시 입력하세요.

### 로그에 `API 요청 실패: 429 OPENAPI00007`

요청량 초과입니다. 폴링 주기를 늘리거나 아이템 수를 줄이거나 서비스 단계로 전환하세요. ([API 제한 사항](#api-제한-사항) 참고)

### 로그에 `경매장 데이터 부족`

해당 아이템의 매물이 2개 미만입니다. 아이템 이름이 정확한지(게임 내 표기와 동일한지) 확인하세요.

### 토스트 알림이 안 보임

Windows 설정 → 시스템 → 알림에서 알림이 켜져 있는지, 집중 지원(방해 금지) 모드가 아닌지 확인하세요.

### 프로그램이 안 보이는데 계속 실행 중

트레이로 최소화된 상태입니다. 트레이 아이콘을 눌러 **열기** 하거나 **종료**로 완전히 끌 수 있습니다.
